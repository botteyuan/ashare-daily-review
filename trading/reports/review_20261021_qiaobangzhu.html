复盘摘要

  • 系统一句话（原话）：在龙头股沿着 5 日均线低吸，第二天冲高出货，没有一个打板进的；部分是下探前日涨停价位置买入。
  • 本质：龙头股 + 回踩低吸 + 次日冲高兑现的超短模式，配合融资杠杆与单票满仓，1–3 个交易日完成一个循环。
  • 选股共性：11 场战役全部做当时主线龙头（高铁总龙头中国南车、地产权重保利地产、题材连板龙罗顿发展/联创节能等），从不碰杂毛。
  • 风控共性：买错当日就纠错（天津松江尾盘跳水果断减仓），不排一字板、不扛单。
  • 最大局限：样本为"经典战役"精选，存在幸存者偏差；且处于 2012–2015 题材牛市环境。

二、交易系统拆解（五要素）

1. 选股：只做龙头，不做杂毛

  • 样本 11 战全部是当期主线最核心标的：主题总龙头（中国南车）、板块权重旗手（保利地产）、题材连板龙（罗顿发展、联创节能、凤凰光学、金轮股份）。
  • 介入前提是"已证明的强"——涨停/连板/领涨在先，他做的是强者的回调，而不是埋伏弱者。

2. 买点：低吸为主，四种入口（按出现频率排序）

入口定义案例
主模式：5日线低吸强势龙头上涨途中回踩 5 日均线，分时回踩均价线（黄线）缩量企稳即接上海莱士、联建光电、中国南车
下探前日涨停价盘中回踩到前日涨停价位置不破，直接接金轮股份（开盘急跌接）
首阴战法连板后首根放量阴线，盘中急杀 4–6% 企稳低吸，赌次日反包罗顿发展
高位追击（少数）连续涨停加速段半路扫入——注意：是买在拉升半路，不是排一字板联创节能、凤凰光学

原话"没有一个打板进的"指的是不排涨停板委托抢封单；凤凰光学"买入涨停"是股价运行至涨停价过程中的主动性买入，两者不矛盾。

3. 卖点：次日冲高出货，卖在加速段

  • 标准动作：次日早盘冲高（09:30–10:30 高开急拉段）分批卖出，不贪尾段——上海莱士、金轮股份、保利地产、中国南车全是早盘兑现。
  • 卖飞可回补：东易日盛 55.5 卖出后 48.3 买回，围绕龙头反复做 T，直到趋势走坏（3/7 收尾）才结束。
  • 日内 T 降成本：中国南车一进一出日内完成 12.0 卖 / 12.23 买 / 12.71 卖 / 12.49 买（融资账户担保品买卖实现变相 T+0）。

4. 仓位：单票满仓 + 融资杠杆 + 金字塔加码

  • 每场战役只做一个标的，全仓进出；百万级后全部走融资（"融资买入 / 担保品买入"）。
  • 分批加码方向是"越涨越加 / 越跌越接"的金字塔式建仓：保利地产 9.70 → 9.87 → 9.91 → 10.07 连续四笔加满。

5. 风控：纠错以"日"为单位，绝不隔夜扛错

  • 天津松江：买入当日尾盘跳水，14:30 果断 7.44–7.45 减仓止损，次日冲高出剩余——单笔错误当天处理，不等下一个"理由"。
  • 不碰一字板（买不进、出不来），所有介入点都留有当日可撤退的流动性。

四、可迁移的规则化清单

  1. 池子：只做当日/当周最强主线的前两名龙头，其余一律不看。
  2. 进场：强趋势回踩 5 日线 ± 分时均价线企稳；或回踩前日涨停价不破；或连板首阴急杀企稳。三者之外不买。
  3. 禁止：不排一字板、不买下降通道、不在分时均价线下方追。
  4. 出场：默认次日冲高出；若高开超预期可锁仓，但最长 3 个交易日强制了结。
  5. 纠错：买入当日跌破介入逻辑位（分时低点 / 前日涨停价）→ 当日减仓，不留隔夜错误。
  6. 资金：单票集中；加仓只在盈利方向上加（金字塔），亏损单只减不加。

五、风险与局限（照搬前必须知道）

  1. 幸存者偏差：交割单只贴"经典之战"，整体胜率、最大回撤、失败单全部未披露——按这套打法照抄，先亏的很可能就是被隐去的那些单。
  2. 时代适配：2012–2015 是题材股黄金期（创业板牛市 + 2014 底蓝筹暴动 + 融资盘增量市），龙头低吸的赔率与当下市场结构不同。
  3. 杠杆双刃剑：全场融资，赚时 130 倍，错时同样 130 倍速度亏；无杠杆复刻应把仓位上限降一档。
  4. 做 T 依赖融资账户：担保品买卖实现的日内回转，普通账户做不了，对应能力缺失时卖点纪律要更保守。
  5. 首阴/追击是高阶动作：需要对情绪周期、量能结构的盘感，退潮期这两招胜率骤降，普通投资者建议只学主战法（5 日线低吸）。

六、一句话收尾

"在龙头股沿着 5 日均线低吸，第二天冲高出货。"——快进快出是表象，本质是：只做最强的票、只在回调中拿筹码、只在加速中交筹码、错了当天认。
