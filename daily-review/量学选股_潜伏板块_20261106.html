《伏击涨停》——量柱识别与伏击圈
  • 第4章「量柱七因子」：高低平倍梯缩金，低量柱 / 倍量柱 / 缩量柱最有价值；「向左看，就近比」。
  • 第4/5章：「价升量缩」的缩量柱是培育黄金柱的酵母；三先规律（卖在买先、价在量先、庄在散先）。
  • 第8章：将军柱 / 黄金柱 / 元帅柱三标准，矮将军「柱不在高，含金则立」。
  • 第9章：金线战法伏击圈——以黄金柱后三日实底/虚底画线，回踩不破即伏击位。
  • 第14章：长阴短柱战法——长阴配短量是主力假跌洗盘，非出逃。
  • 第3章：十二字令、小倍阳选股公式；多重基因共振才是涨停先兆。
《涨停密码》——基因组合成密码
  • 前言：基因是单个因子，密码是多个基因的排列组合；「至少 2~3 个涨停基因组合才能生成涨停密码」。
  • 第2章：凹口淘金三要素——突然凹陷(长阴短柱) + 凹口平衡线 + 凹底两个将军柱(刹车/换挡)。
  • 第3章：凹底矮将军 / 黄金线上阳盖阴，逢低介入七成金。
  • 第5章：接力小双阳——两小倍阳隔 3~5 日踩同一精准线，左刹车右换挡。
  • 第6章：双阴洗盘三要素——上升通道 + 回踩攻防线 + 随后阳盖阴确认。
  • 第7/8/12/17章：回踩精准线、假阴真阳「习惯证明存在」「位置决定性质」、价升量缩、牛股三绝（倍量不穿/高量不破/跳空不补）。
